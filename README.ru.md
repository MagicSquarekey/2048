## ✨ Особенности

- 🎨 **Тема «глубокий космический неон»**: индиговый градиентный фон с дрейфующими свечениями, стеклянные карточки и плитки с градиентами, окантовкой и неоновым сиянием
- ⚡ **Плавное управление**: очередь ввода + непрерывное скольжение при удержании (~7 ходов/сек) + анимации, независимые от частоты кадров — быстрые комбо не теряют ввод
- 💥 **Анимации и эффекты**: взрывы частиц при слиянии, тряска экрана на крупных слияниях, конфети победы, анимированный переход конца игры, затухания страниц
- 🌍 **Двуязычный интерфейс**: переключение между китайским и английским одним нажатием в игре

## 🎮 Режимы игры

| Режим | Описание |
|------|----------|
| **Классика** | Без ограничения по времени — погоня за лучшим счётом |
| **На время** | Наберите целевой счёт за 60 секунд |
| **Испытание** | Соберите плитку 128 за 50 ходов |

**Управление**: стрелки / WASD / свайп мышью · `ESC` для паузы

## 🧰 Бонусы

- **Отмена**: откат последнего хода (3 за игру)
- **Очистка**: убрать самую маленькую плитку (1 за игру)
- **Возрождение**: после конца игры уберите две самые маленькие плитки и продолжайте

## 🏆 Прочие функции

- Система достижений (6 достижений для разблокировки)
- Отслеживание лучшего счёта / общего числа игр
- Значок нового рекорда + анимация набора очков на странице результатов
- Переключатели звуковых эффектов и фоновой музыки

## 🖥️ Системные требования

- Windows 10 / 11
- Python 3.10+
- Pygame 2.6.1

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск игры

```bash
python src/main.py
```

### 3. Сборка в EXE

```bash
# Сборка в один клик (рекомендуется)
python scripts/build_auto.py

# Интерактивная сборка
python scripts/build.py
```

Исполняемый файл окажется в `dist/2048/2048.exe` — дважды щёлкните, чтобы играть, без Python и зависимостей. Подробнее см. [scripts/README.md](scripts/README.md).

## 📁 Структура проекта

```
2048/
├── src/                    # Исходный код
│   ├── main.py             # Точка входа
│   ├── config.py           # Глобальная конфигурация (тема / анимация / ввод)
│   ├── i18n.py             # Локализация (китайский и английский)
│   ├── utils.py            # Помощники отрисовки, кэши, кривые анимации
│   ├── models/             # Модели данных (поле / состояние / сохранение / достижения)
│   └── views/              # Слой представления
│       ├── ui_components.py  # UI-компоненты (кнопки / карточки счёта / переключатели / оповещения)
│       ├── board_view.py     # Отрисовка и анимация поля
│       ├── effects.py        # Система частиц и тряска экрана
│       ├── sound_manager.py  # Управление звуком
│       └── pages/            # Страницы (меню / игра / результат / настройки / достижения / пауза / вход)
├── tests/                  # Тесты (359 модульных тестов + E2E-симуляция пользователя)
├── scripts/                # Скрипты сборки и упаковки
├── docs/                   # Документация
├── private/                # Приватные файлы
├── dist/                   # Вывод сборки (.gitignore)
├── build/                  # Временные файлы сборки (.gitignore)
└── requirements.txt        # Список зависимостей
```

## 🔧 Руководство по разработке

### Запуск тестов

```bash
# Все модульные тесты
python -m pytest tests/

# Сквозная симуляция пользователя (E2E)
python tests/e2e_user_simulation.py

# Съёмка скриншотов UI
python tests/capture_ui_review.py
```

Покрытие: алгоритм поля, состояние игры, полные жизненные циклы трёх режимов, бонусы, пауза/рестарт, комбо с очередью ввода, нагрузочное тестирование и бюджет производительности 60FPS.
